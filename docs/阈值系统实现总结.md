## 🔧 核心功能

### 1. 灵活的阈值配置

- **按客户配置**: 不同客户可以有不同的阈值标准
- **按资产类型配置**: 同一客户的不同资产类型可以有不同阈值
- **全局默认**: 没有特定配置时使用全局默认值

### 2. 多种阈值方向

| 方向 | 说明 | 示例 |
|------|------|------|
| upper | 越高越严重 | CPU使用率、内存使用率 |
| lower | 越低越严重 | 缓冲命中率、可用空间 |
| range | 偏离范围严重 | 响应时间、温度 |
| exact | 精确匹配 | 状态码、错误类型 |

### 3. 模板系统

- 预定义了 **20+ 常用阈值模板**
- 覆盖 MySQL、Oracle、MSSQL、PostgreSQL、SNMP、SSH、Ping
- 支持一键应用到客户

### 4. 向后兼容

- 如果没有配置阈值，使用原有逻辑（fail=错误，warning=警告）
- 不影响现有系统的正常运行

## 📊 默认阈值建议

### 数据库类

| 检查项 | 警告 | 错误 | 严重 | 方向 |
|--------|------|------|------|------|
| 会话连接数 | >100 | >200 | >300 | upper |
| 缓冲命中率 | <95% | <90% | <80% | lower |
| 表空间使用率 | >80% | >90% | >95% | upper |

### 服务器/设备类

| 检查项 | 警告 | 错误 | 严重 | 方向 |
|--------|------|------|------|------|
| CPU使用率 | >80% | >90% | >95% | upper |
| 内存使用率 | >80% | >90% | >95% | upper |
| 磁盘使用率 | >80% | >90% | >95% | upper |
| 系统负载 | >4 | >8 | >16 | upper |

### 网络类

| 检查项 | 警告 | 错误 | 严重 | 方向 |
|--------|------|------|------|------|
| 响应延迟 | >100ms | >500ms | >1000ms | upper |
| 丢包率 | >1% | >5% | >10% | upper |

## 📝 使用示例

### 场景 1：为医院客户配置更严格的 Oracle 表空间阈值

```bash
# 1. 获取模板列表
curl http://localhost:8000/api/alerts/threshold-templates/?protocol=oracle

# 2. 应用模板到客户
curl -X POST http://localhost:8000/api/alerts/threshold-templates/1/apply_to_customer/ \
  -H "Content-Type: application/json" \
  -d '{"customer_id": 1, "asset_type_id": 3}'

# 3. 修改为更严格的阈值
curl -X PUT http://localhost:8000/api/alerts/thresholds/1/ \
  -H "Content-Type: application/json" \
  -d '{
    "warning_threshold": "70",
    "error_threshold": "80",
    "critical_threshold": "90"
  }'
```

### 场景 2：测试阈值配置

```bash
# 测试单个值
curl -X POST http://localhost:8000/api/alerts/thresholds/1/test_value/ \
  -H "Content-Type: application/json" \
  -d '{"value": "85"}'

# 批量测试
curl "http://localhost:8000/api/alerts/thresholds/batch_check/?items=CPU_USAGE:85&items=MEM_USAGE:92&customer=1"
```

## 🔄 与现有系统的集成

### 告警生成流程变化

**之前（硬编码）:**
```python
if r.status == 'fail':
    severity = 3  # 固定错误
elif r.status == 'warning':
    severity = 2  # 固定警告
```

**之后（阈值配置）:**
```python
# 使用阈值配置判断严重程度
severity, severity_name = determine_severity(
    check_item_code=r.check_item_code,
    result_value=r.result_value,
    status=r.status,
    customer_id=customer.id,
    asset_type_id=asset.asset_type_id
)
```
