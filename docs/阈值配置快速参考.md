# 告警阈值配置 - 快速参考

## 🚀 快速开始

### 1. 初始化（只需一次）

```bash
# 执行迁移
cd backend && python manage.py migrate alerts

# 初始化模板
cd .. && python scripts/init_threshold_templates.py
```

### 2. 从模板创建（推荐）

```bash
# 1. 获取模板
GET /api/alerts/threshold-templates/?protocol=mysql

# 2. 应用到客户
POST /api/alerts/threshold-templates/{id}/apply_to_customer/
{
    "customer_id": 1,
    "asset_type_id": 2  # 可选
}
```

### 3. 手动创建

```bash
POST /api/alerts/thresholds/
{
    "customer": 1,
    "protocol": "ssh",
    "check_item_code": "CPU_USAGE",
    "check_item_name": "CPU使用率",
    "threshold_direction": "upper",
    "warning_threshold": "80",
    "error_threshold": "90",
    "critical_threshold": "95",
    "unit": "%"
}
```

## 📊 默认阈值速查表

### 数据库（MySQL/Oracle/MSSQL/PostgreSQL）

| 检查项 | 警告 | 错误 | 严重 | 方向 |
|--------|------|------|------|------|
| 会话数 | >100 | >200 | >300 | ↑ |
| 命中率 | <95% | <90% | <80% | ↓ |
| 表空间 | >80% | >90% | >95% | ↑ |

### 服务器/设备（SSH/SNMP）

| 检查项 | 警告 | 错误 | 严重 | 方向 |
|--------|------|------|------|------|
| CPU | >80% | >90% | >95% | ↑ |
| 内存 | >80% | >90% | >95% | ↑ |
| 磁盘 | >80% | >90% | >95% | ↑ |
| 负载 | >4 | >8 | >16 | ↑ |

### 网络（Ping）

| 检查项 | 警告 | 错误 | 严重 | 方向 |
|--------|------|------|------|------|
| 延迟 | >100ms | >500ms | >1000ms | ↑ |
| 丢包 | >1% | >5% | >10% | ↑ |

## 🔍 常用查询

```bash
# 查看某客户的阈值
GET /api/alerts/thresholds/?customer=1

# 查看某协议的所有阈值
GET /api/alerts/thresholds/?protocol=oracle

# 测试阈值
POST /api/alerts/thresholds/{id}/test_value/ {"value": "85"}

# 批量测试
GET /api/alerts/thresholds/batch_check/?items=CPU_USAGE:85&items=MEM_USAGE:92
```

## ⚡ 阈值方向说明

| 方向 | 含义 | 示例 |
|------|------|------|
| `upper` | 越高越严重 | CPU、内存、磁盘 |
| `lower` | 越低越严重 | 命中率、可用空间 |
| `range` | 偏离中心严重 | 温度、延迟 |
| `exact` | 精确匹配 | 错误码、状态 |

## 🎯 严重程度等级

| 级别 | 名称 | 图标 | 处理要求 |
|------|------|------|----------|
| 1 | 信息 | ℹ️ | 无需立即处理 |
| 2 | 警告 | 🟡 | 需要关注 |
| 3 | 错误 | 🔴 | 尽快处理 |
| 4 | 严重 | 🚨 | 立即处理 |

## 📝 配置优先级

```
客户 + 资产类型 > 客户 > 全局
```

**示例：**
- 配置A：客户1 + Oracle + TABLESPACE = 警告70%
- 配置B：客户1 + TABLESPACE = 警告75%
- 配置C：TABLESPACE = 警告80%

客户1的Oracle资产使用配置A（70%）
客户1的MySQL资产使用配置B（75%）
客户2的Oracle资产使用配置C（80%）
